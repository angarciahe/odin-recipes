# odin-recipes
HTML webpage for Odin

This project will create a webpage of simple recipes as determined by The Odin Project (TOP). At the end the following skills will have been used:
<ul>
    <li>HTML local creation and ordering of pages and related files.</li>
    <li>Correct use of HTML elements (titles, paragraphs, lists, etc.).</li>
    <li>Correct use of hyperlinks on absolute and relative URLs.</li>
    <li>Add images in preferred formats (.jpg, .gif, .png, .svg).</li>
    <li>Efficient use of Git, Github and adequate logs with appropiate commits.</li>
</ul>
